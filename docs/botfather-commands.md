# BotFather Commands

## How to register

1. Open a chat with [@BotFather](https://t.me/BotFather).
2. Send `/setcommands`.
3. Select this bot from the list.
4. Send the block below as a single message.

## Command list

```
quiz - Get a random phrase quiz (multiple choice, EN<->ID)
fillblank - Fill in the missing word from a random phrase
add - Add a new phrase (admin only)
bulk - Add multiple phrases at once, one per line (admin only)
```

---

This document provides instructions for registering bot commands with Telegram's BotFather. The bot is an Indonesian-phrase learning service ("nyegerake") featuring two quiz modes for practicing phrase meanings and two admin-only commands for managing the phrase bank.
